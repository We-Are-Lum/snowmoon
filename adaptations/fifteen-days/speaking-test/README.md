# Speaking-shot test

Three close-ups from the version 2 cut where one character speaks and is the main face, each with its finished line
trimmed to the speech plus about 0.3 s either side. The owner runs them through Hedra (a closed model) by hand; the
coding agent runs them through InfiniteTalk (open weights, Apache-2.0) on Modal. A side-by-side clip of Hedra, the open
model and the current still follows, for the owner to judge. Not part of the film. `recipe.json` names every input, its
source and sha256. The frames are the version 2 pictures (GPT Image 2.5 Sunburst, a closed model), AI-generated, not by
the author.
