OPEN ISSUES
Board 1c doesn't match this engine. 1c uses 5×5 player symbols. This copy uses a 4-cell symbol that cycles through 12 arrangements. One of them needs to change before matches are built.
Rock behaviour is my choice. Any block containing a rock flips top-to-bottom. That bounces gliders, but they briefly overlap rock cells, which are drawn as cyan on grey.
Screen 8 forms the symbol at turn 20, not at turn 12 as the JSON strip says. The setup was found by search: one glider and two rocks, where removing either rock means no symbol forms.
Screen 12 is a stand-in. The chapter 4 figure (c4-b5) and its reconstructed right half aren't in this project, so a seeded random board plays in its place.
Data model: claim ids like c4-b79 and ranges like c4-b106–c4-b108 are strings, not block references, so they break when the text is re-ingested. They should point to (chapter, block id) rows.
